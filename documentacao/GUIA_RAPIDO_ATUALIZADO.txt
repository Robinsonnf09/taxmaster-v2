🆘 SOLUÇÃO DE PROBLEMAS

❌ Erro 401 (Unauthorized):
   → API Key inválida ou expirada
   → Verificar se copiou a chave completa
   → Consultar https://datajud.cnj.jus.br/ para nova chave

❌ Erro 404 (Not Found):
   → Tribunal incorreto (usar sigla: TJGO, TJSP, etc.)
   → Processo não existe ou número errado

❌ Erro de conexão:
   → Verificar internet
   → Firewall/proxy bloqueando
   → API temporariamente indisponível

✅ Nenhum resultado encontrado:
   → Normal! Nem todos os processos estão no DataJud
   → Processo pode ser sigiloso
   → Dados podem não ter sido enviados pelo tribunal
