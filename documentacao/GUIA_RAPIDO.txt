  SISTEMA DE PRECATÓRIOS - GUIA DE USO RÁPIDO
═══════════════════════════════════════════════════════════════

1. OBTER API KEY DO DATAJUD CNJ
   → Acesse: https://datajud.cnj.jus.br/
   → Cadastre sua consultoria
   → Solicite a API Key
   → Aguarde aprovação (1-3 dias úteis)

2. TESTAR CONECTIVIDADE
   .\scripts\Test-APIDataJud.ps1 -ApiKey "SUA_CHAVE_AQUI"

3. CONSULTAR PROCESSOS

   Por número:
   .\scripts\Get-ProcessosPrecatorios.ps1 -Tribunal "TJGO" -ApiKey "SUA_CHAVE" -NumeroProcesso "5273405-44.2025.8.09.0051"

   Por CPF:
   .\scripts\Get-ProcessosPrecatorios.ps1 -Tribunal "TJGO" -ApiKey "SUA_CHAVE" -CPF "027.691.641-71"

   Por nome:
   .\scripts\Get-ProcessosPrecatorios.ps1 -Tribunal "TJGO" -ApiKey "SUA_CHAVE" -NomeParte "IGOR JACOMO"

4. IMPORTAR PARA EXCEL
   .\scripts\Export-PrecatoriosToExcel.ps1 -JsonPath ".\resultados\processos_TJGO_*.json"
